      How it works

      1. IngestEvery hour a GitHub Actions job pulls 92 days of hourly pollution (CAMS) and weather from the Open-Meteo APIs.
      2. Features48 hours of PM2.5 lags, rolling statistics, other pollutants, and the weather forecast for the target hour.
      3. TrainOnce a day XGBoost and LightGBM compete against a persistence baseline. The winner is promoted automatically.
      4. ForecastOne direct model predicts 1 to 24 hours ahead for every city and logs each prediction.
      5. MonitorLogged forecasts are scored against what actually happened, giving live accuracy.
      6. ServeThis page is rebuilt on GitHub Pages. The same model ships as a FastAPI Docker image on GHCR.

      Built with Python, pandas, XGBoost, LightGBM, scikit-learn, FastAPI, Docker, GitHub Actions, GitHub Pages, Jenkins and Terraform for AWS Lambda.

      Data: Open-Meteo Air Quality API (Copernicus CAMS) and Open-Meteo Weather. AQI uses CPCB National AQI breakpoints applied to hourly values. Not for health decisions.
